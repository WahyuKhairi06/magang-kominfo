# 📖 Tentang Project

Website Puskesmas Marunggi merupakan sistem informasi berbasis web yang dirancang untuk meningkatkan kualitas pelayanan informasi kesehatan kepada masyarakat.

Website ini menyediakan berbagai layanan digital seperti informasi pelayanan, jadwal dokter, berita kesehatan, pengaduan masyarakat, serta akan dikembangkan dengan fitur **Artificial Intelligence (AI Healthcare Assistant)** sebagai asisten virtual resmi Puskesmas.

Project ini dikembangkan sebagai bagian dari kegiatan **Praktik Kerja Lapangan (PKL)** di Dinas Komunikasi dan Informatika Kota Pariaman.

# ⚙️ Instalasi

Clone repository

```bash
git clone https://github.com/username/project.git
```

Masuk ke folder

```bash
cd project
```

Install Composer

```bash
composer install
```

Copy Environment

```bash
cp .env.example .env
```

Generate Key

```bash
php artisan key:generate
```

Migrasi Database

```bash
php artisan migrate
```

Install Node Modules

```bash
npm install
```

Jalankan Vite

```bash
npm run dev
```

Jalankan Laravel

```bash
php artisan serve
```

Website akan berjalan di

```
http://127.0.0.1:8000
```
